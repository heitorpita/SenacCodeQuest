# UC08 — React Native

Desenvolvimento de aplicativos mobile com React Native e Expo.

## Projetos

| Pasta | Projeto | Descrição |
|-------|---------|-----------|
| [frasesApp](./frasesApp/) | App de Frases Motivacionais | Aplicativo mobile que exibe frases motivacionais aleatórias |

## Como Criar um Novo Projeto

```bash
npx create-expo-app meuApp --template blank
cd meuApp
code .
```

## Como Executar

```bash
# Android
npm run android

# iOS
npm run ios

# Web (para desenvolvimento)
npm run web
```

> Ao executar pela primeira vez no modo web, instale as dependências adicionais:
> ```bash
> npx expo install react-dom react-native-web
> ```

## Tecnologias

- React Native
