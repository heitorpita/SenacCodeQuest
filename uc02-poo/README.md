# UC02 — Programação Orientada a Objetos

Conceitos de POO com JavaScript: classes, construtores, herança, polimorfismo e encapsulamento.

## Aulas

| Pasta | Conteúdo |
|-------|----------|
| [aula01](./aula01/) | Classes e construtores — modelagem de `Usuario` e `Jogo` |
| [aula02](./aula02/) | Mais classes: `ContaBancaria` e `Livro` com atributos e métodos |
| [aula03](./aula03/) | Sistema de apostas com dados — classes `Dado`, `Jogador` e `SistemaAzar` |
| [aula04](./aula04/) | Herança e polimorfismo — hierarquia `Animal > Mamifero / Ave` |

## Destaques

- **aula02/Banco**: simula operações de conta bancária (depósito, saque, saldo)
- **aula03/aposta**: sistema de jogo com dados e múltiplos jogadores
- **aula04/Desafio**: polimorfismo com animais usando `extends` e `super`

## Tecnologias

- JavaScript (Node.js)
