# UC07 — Desenvolvimento Frontend

Do HTML/CSS básico ao React moderno com Vite. Cobre fundamentos de web design, componentes, estado e roteamento.

## Conteúdo

| Pasta | Projeto | Descrição | Tecnologias |
|-------|---------|-----------|-------------|
| [aulasHTML](./aulasHTML/) | Aulas de HTML/CSS | Exercícios de web design: layout, formulários, responsividade | HTML5, CSS3 |
| [React-Senac](./React-Senac/) | Introdução ao React | Primeiros componentes, props e estado | React, Vite |
| [TodoList-React](./TodoList-React/) | Lista de Tarefas | CRUD de tarefas com componentes e estado local | React, Vite |
| [CatalogoLivrosReact](./CatalogoLivrosReact/) | Catálogo de Livros | Listagem de livros com Header, Footer e cards | React, Vite |
| [SuperEventos-React](./SuperEventos-React/) | Super Eventos | Gerenciador de eventos com cards e listagem | React, Vite |
| [adotepolvo](./adotepolvo/) | Adote Polvo | App de adoção de pets com múltiplas páginas e rotas | React, Vite, React Router |

## Progressão

```
aulasHTML → fundamentos HTML/CSS
React-Senac → componentes básicos
TodoList-React → estado (useState)
CatalogoLivrosReact → componentização
SuperEventos-React → props e listas
adotepolvo → roteamento e páginas completas
```

## Como Executar (projetos React)

```bash
cd <nome-do-projeto>
npm install
npm run dev
```

## Tecnologias

- HTML5, CSS3
- React 19, Vite
- React Router DOM
