# UC03 — Desenvolvimento Backend

| Pasta | Conteúdo |

| [aula04](./aula04/) | Manipulação de arquivos avançada |
| [aula05](./aula05/) | Criação e configuração de `package.json` |
| [aula06](./aula06/) | Introdução ao Express |
| [aula07](./aula07/) | MVC com Express — API de Livros |
| [aula08](./aula08/) | MVC — API de Alunos |

| [aula10](./aula10/) | Refatoração MVC — Usuários v2 |
| [aula11](./aula11/) | MVC versão final com boas práticas |

## Progressão

```

```
